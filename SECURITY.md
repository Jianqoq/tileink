# Security policy

## Supported versions

Tileink is currently pre-1.0. Security fixes are applied to the latest release and the `main`
branch; older revisions are not maintained as separate security branches.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting](https://github.com/Jianqoq/tileink/security/advisories/new) so the
report, reproduction, and remediation discussion remain private.

Include the affected revision, impact, reproduction steps, and any known mitigations. You should
receive an acknowledgement within seven days. Disclosure timing will be coordinated after a fix is
available; please do not publish the report before that point.

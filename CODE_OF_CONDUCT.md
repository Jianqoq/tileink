# Code of Conduct

Tileink follows the
[Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
By participating in this project, you agree to uphold that standard in project spaces and in public
spaces when representing the project.

Report conduct concerns privately through the maintainer's
[GitHub profile](https://github.com/Jianqoq). Reports will be reviewed promptly, handled as
confidentially as practical, and assessed consistently with the Contributor Covenant enforcement
guidelines. Reports made in bad faith may be rejected.
